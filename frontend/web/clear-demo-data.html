Timely Mate - Clear Demo Data

This tool will clear all Timely Mate data from your browser's localStorage, allowing you to test the application as a new user without any demo data.

Success! All demo data has been cleared from localStorage.

Alternative Methods:

If the button above doesn't work, you can also clear the data using one of these methods:

1. Using Browser Console

Open your browser's developer tools (F12 or Right-click > Inspect), go to the Console tab, and run:

localStorage.clear(); console.log('All data cleared!');

2. Using Browser Settings

Go to your browser settings, find "Privacy and Security" > "Clear browsing data" > Select "Cookies and site data" > Clear data
